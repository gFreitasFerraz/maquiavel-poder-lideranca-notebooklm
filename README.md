# Nicolau Maquiavel: Poder, Liderança e Estratégia com NotebookLM
> Caderno temático desenvolvido como parte do Desafio de Projeto da DIO, utilizando o NotebookLM como ferramenta de aprendizagem ativa para investigar as ideias de Nicolau Maquiavel relacionadas a poder, liderança, estratégia e manipulação.

Nicolau Maquiavel é frequentemente associado à manipulação, à busca pelo poder e à ideia de que os fins justificam os meios. Entretanto, uma análise mais cuidadosa de O Príncipe revela uma discussão mais ampla sobre liderança, estratégia, estabilidade política, comportamento humano, reputação e manutenção do poder.

Este projeto busca utilizar o NotebookLM como ferramenta de aprendizagem ativa para analisar essas ideias a partir de diferentes fontes, evitando uma interpretação baseada exclusivamente em frases isoladas ou no senso comum associado ao termo "maquiavélico".

## Objetivo geral
 Investigar as principais ideias de Nicolau Maquiavel relacionadas ao poder, liderança, estratégia e comportamento humano, utilizando o NotebookLM para organizar, comparar e questionar diferentes fontes.

## Objetivos específicos
Compreender as principais ideias apresentadas em O Príncipe;

Identificar conceitos relacionados à liderança e manutenção do poder;

Analisar a relação entre medo, respeito, reputação e autoridade;

Investigar o conceito de virtù e sua relação com a fortuna;

Analisar criticamente a associação entre Maquiavel e manipulação;

Comparar diferentes interpretações sobre suas ideias;

Utilizar IA para sintetizar e organizar o conhecimento;

Avaliar criticamente as respostas produzidas pelo NotebookLM.
